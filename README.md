## Visitor paths

- Ask Harsha: a free portfolio guide with 24 prepared topics, question matching, brief/detailed answers, follow-up suggestions, source links, and copy/reset controls. Available in both visitor modes. This is a prepared-answer guide, not a live AI model or open-ended technical assistant.
- Explore: leadership, causal inference, RCTs/A-B tests, difference-in-differences, five searchable case studies, experience and contact.
- Recruiter brief: four role lenses (leadership, hands-on science, product/delivery, experimentation), a copyable introduction, share link, résumé/CV, and print/save-as-PDF.
- The Decision Room: three fictional AI product decisions, explanatory feedback, illustrative emphasis points, replay and a copyable debrief linked to actual work.
- The Curiosity Files: four optional field notes. Follow the opening spark, type THINK outside text fields, open three case studies, or finish the game. Equivalent clue/reveal buttons support touch and keyboard use. Discovery progress supports reset and undo.
- Quick navigation: use Jump to, Cmd/Ctrl+K, or / outside text fields.

## Update the website

The complete website is in `index.html`, including styles, interactions, and the prepared knowledge in the `portfolio-guide-knowledge` JSON block. Edit and commit to the `main` branch. GitHub Pages publishes from the repository root. There is no build step, dependency installation, API key, database or paid AI service.

The two PDFs are public-facing résumé and CV editions. Replace them using the same filenames to retain their links. Review all new public content before uploading, including knowledge records, source links, documents and metadata.

## Local preview

Open `index.html` in a browser, or serve this folder with a local static web server. Clipboard actions work best on HTTPS or localhost; visible text and links remain available if copying is unavailable.

## Accessibility and privacy

Semantic sections, visible keyboard focus, native case-study disclosures, mobile navigation, reduced-motion support, and print styles are included. Core career content and downloads remain available without JavaScript. The guide, game, and navigation shortcuts require JavaScript.

View preference and discovery progress are saved only in the visitor’s browser, when storage is available. The site has no analytics, tracking scripts, login, form submission, or external AI service. Guide questions and answers stay in page memory and are cleared by reload or Start over. Copy conversation writes text and source links to the visitor’s clipboard only when clicked. Game choices are not submitted or retained after reload. Reset clears discovery progress, while Undo restores it during the visit. GitHub Pages still serves the site under its own hosting policies.

The knowledge bundle contains only public career summaries and general technical approaches. It excludes employer scoring formulas, model architecture, training data, customer identities, internal financial details, and trial-level statistics. Boundary responses help explain this scope; confidentiality depends on keeping such material out of every public file, not on client-side filtering. All shipped HTML, JavaScript, JSON and PDFs are publicly readable.

Case studies describe personal contributions within collaborative teams. Career figures are self-reported résumé results. The Vizit RCT narrative is limited to randomized evaluation of a scoring improvement during a controlled rollout. No assignment units, sample sizes, p-values or quantified uplift are claimed. Generic technical guidance is labeled separately from career experience. Fictional game scenarios are illustrative.

These replacements update the current website and downloads. They do not erase older Git commits, previously downloaded documents or third-party caches.
