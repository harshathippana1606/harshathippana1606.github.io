# Jaya Harsha Thippana — Portfolio

A responsive portfolio covering AI leadership, scientific decisions, career experience, and production machine learning.

Live website: https://harshathippana1606.github.io/

## Update the website

The complete website is in `index.html`, including its styles and small interactions. Edit this file, then commit the change to the `main` branch. GitHub Pages publishes from the repository root.

The two PDF files preserve the résumé and CV linked from the previous portfolio. Replace either file with an updated PDF using the same filename to keep the links working.

## Local preview

Open `index.html` in a browser, or serve this folder with a local static web server. No build step, package installation, API key, database, or paid hosting is required.

## Content and accessibility

The site uses semantic sections, keyboard-accessible case-study disclosures, visible focus states, mobile navigation, reduced-motion support, and print styles. Core career content and downloads work without JavaScript.

Case studies describe personal contributions within collaborative teams. Career metrics are self-reported résumé results; predictive evidence is distinguished from causal business impact. No private interview documents, internal source material, or unpublished patent details are included.
