## Visitor paths

- Explore: leadership, causal inference, RCTs/A-B tests, difference-in-differences, five searchable case studies, experience and contact.
- Recruiter brief: four role lenses (leadership, hands-on science, product/delivery, experimentation), a copyable introduction, share link, résumé/CV, and print/save-as-PDF.
- The Decision Room: three fictional AI product decisions, explanatory feedback, illustrative emphasis points, replay and a copyable debrief linked to actual work.
- The Curiosity Files: four optional field notes. Follow the opening spark, type THINK outside text fields, open three case studies, or finish the game. Equivalent clue/reveal buttons support touch and keyboard use. Discovery progress supports reset and undo.
- Quick navigation: use Jump to, Cmd/Ctrl+K, or / outside text fields.

## Update the website

The complete website is in `index.html`, including styles and interactions. Edit this file and commit to the `main` branch. GitHub Pages publishes from the repository root. There is no build step, dependency installation, API key, database or paid hosting requirement.

The two PDF files preserve the résumé and CV from the previous portfolio. Replace either PDF using the same filename to retain its links.

## Local preview

Open `index.html` in a browser, or serve this folder with any local static web server. Clipboard actions work best on HTTPS or localhost; visible text and links remain available if copying is unavailable.

## Accessibility and privacy

Semantic sections, visible keyboard focus, native case-study disclosures, mobile navigation, reduced-motion support, and print styles are included. Core career content and downloads remain available without JavaScript. The game and navigation shortcuts require JavaScript.

View preference and discovery progress are saved only in the visitor’s browser, when storage is available. The site has no analytics, tracking scripts, login, form submission, or external AI service. Game choices are not submitted or retained after reload. Reset clears discovery progress, while Undo restores it during the visit.

Case studies describe personal contributions within collaborative teams. Career figures are self-reported résumé results. The Vizit scoring RCT narrative is based on the owner’s description of shadow-mode evaluation; no trial counts, randomization units or quantified sales-lift claims have been added.
