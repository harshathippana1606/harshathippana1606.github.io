## The experience

- One concise reading path: identity and leadership scope, three visual project stories, career and contact.
- Vizit: randomized evaluation and causal inference, with interactive conceptual explanations of RCTs and difference-in-differences. Study-delivery and efficiency figures are separate from RCT effects.
- Northwestern Mutual: a relative-time graphic illustrates the reported 75% reduction in claims decision time. It is indexed to a starting value of 100, not measured hours.
- Harley-Davidson: function building and the reported $35M annualized revenue associated with prospect identification.
- Project details expand on demand. Legacy case-study links remain supported.
- The 60-second recruiter brief opens in a dialog, with résumé, full CV, contact, copy and print actions.
- Ask Harsha provides 24 prepared, source-linked topics, brief/detailed answers, follow-ups, and copy/reset controls. It is not a live AI model. Cmd/Ctrl+K opens the guide outside text fields.
- The optional lab contains a three-decision fictional game and four discoverable field notes. The opening spark, typing THINK outside text fields, exploring three cases, or finishing the game reveal notes. Touch-accessible clues and reveal controls are also provided.

## Hosting and editing

GitHub Pages publishes the four files in this folder from the repository root on `main`. The website is self-contained in `index.html`, including CSS, JavaScript, and the prepared knowledge in `portfolio-guide-knowledge`. No build, dependencies, backend, API key or paid AI service is required. Replace the public résumé and CV using their existing filenames to keep links working.

Open `index.html` directly or use a local static web server for preview. Clipboard actions work best on HTTPS or localhost.

## Accessibility and privacy

Semantic content, native disclosures and dialogs, keyboard tabs, visible focus, responsive layouts, reduced-motion support and print styles are included. Core career content and PDF downloads work without JavaScript. The guide, recruiter dialog and lab need JavaScript.

The site includes no analytics, tracking scripts, account, form submission or remote AI service. Guide questions remain in page memory; reload or Start over clears the conversation. Copy actions only write to the visitor’s clipboard when requested. Discovery progress is saved in the visitor’s browser and can be reset or restored with Undo. GitHub Pages has its own hosting policies.

All shipped files are public. Public career summaries and general scientific explanations exclude company formulas, model architecture, training recipes/data, private customer identities, internal financial figures, and trial-level statistics. Boundary messages explain this scope; they cannot protect secrets placed in a public file.

Career results are self-reported and attributed to separate initiatives. Method diagrams are conceptual. The game is fictional. These current files do not remove old Git history, previous downloads, the original Sites website or third-party caches.
